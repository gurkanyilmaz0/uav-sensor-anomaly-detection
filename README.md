
# UAV Telemetry Sensor Anomaly Detection

Bu proje, İnsansız Hava Araçları (İHA) ve otonom platformlarda sensör/telemetri verilerini kullanarak anomali ve arızaları önceden tespit eden bir makine öğrenmesi boru hattı içerir.

## 📌 Proje Özeti
* **Kullanılan Modeller:** Lojistik Regresyon & Random Forest Classifier
* **Veri Seti:** UCI AI4I Telemetri / Sensör Veri Seti (Hava/Gövde Sıcaklığı, Devir, Tork, Aşınma)
* **Kritik Parametreler:** Tork (Nm) ve Motor Devri (RPM) anomalilerde en belirleyici özniteliklerdir.
